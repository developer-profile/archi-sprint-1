Задание 1.

---
Использую стратегию вертикальной развёртки

Стратегия вертикальной нарезки позволяет организовать микрофронтендов вокруг конкретных задач.
---
Уровень 1. Проектирование
---



Чтобы перенести монолитную архитектуру приложения в приложение с архитектурой микрофронтендов необходимо логически разделить все основные бизнес-функции приложения:
- Загрузка и удаление фото
- Управление пользовательскими профилями
- Учет статистики сбора и учёт лайков

Архитектура приложения

- Модуль объединяющий микрофронтенты
- Модуль работы с фото
- Модуль управления пользовательскими профилями
- Модуль учёта лайков и другой статистики


Загрузка фронтендов

- Каждый модуль-микрофронтенд будет подгружаться из одного вызывающего модуля

Как будем интегрировать

- Микрофрентенды будут собираться раздельно в рамках индивидуальных процессов CI/CD 

---
Уровень 2. Планирование изменений
---

Под каждый микрофронтенд и подгружающиий фронтенды модуль создаём отдельный проект и передаём отдельным командам.

Команда 1, фреймворк React
 - Микрофронтенд для загрузки фотографий
 - Микрофронтенд для удаления фотография

Команда 2, фреймворк React
 - Микрофронтенд для сбора и учёт лайков
 - Подгружающиий фронтенды модуль

Команда 3, фреймворк React
 - Микрофронтенд для создания профиля и его редактирования


---
Модуль загрузки и удаления фотографий
Описание: Отвечает за загрузку и удаление фотографий

Роли: Обеспечивает базывые функции работы с фото: загрузка, просмотр, изменение, удаление.

---
Модуль загрузки 
Описание: Отвечает за загрузку всех модулей на одной странице

Роли: Обеспечивает отображение вывода каждого модуля на одной странице.

---
Модуль Сбора и учёта статистики по лайкам
Описание: Отвечает за регистрацию в БД обратной связи с пользователями посредством лайков

Роли: Обеспечивает за сбор и учёт количества лайков для каждого фото

---
Модуль Профиля пользователя и его редактирование
Описание: Отвечает создание удобной для пользователя возможности взаимодействовать с приложением.

Роли: Обеспечивает базывые функции работы пользовательским профилем: регистрация, редактирование и удаление.
